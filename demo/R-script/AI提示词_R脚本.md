# AI提示词 - R脚本方案

## 任务描述
我需要创建一个R脚本来绘制四川省样本地理分布图。具体要求如下：

## 数据格式
我有一个TSV格式的数据文件，包含以下列：
- Population_name: 种群名称（如ZJ, PC, JC等）
- Sampling_location: 采样地点描述
- Longitude: 经度（十进制度数，如102.843001）
- Latitude: 纬度（十进制度数，如28.014200）
- Elevation_m: 海拔高度（米）
- Individuals_number: 个体数量

数据示例：
```
Population_name	Longitude	Latitude	Elevation_m	Individuals_number
ZJ	102.843001	28.014200	2300	6
PC	107.104000	31.560500	1338	8
JC	102.064000	31.476301	2150	10
```

## 功能需求
1. **地图底图**：使用四川省地图作为底图（不要显示其他省份）
2. **样本点绘制**：在地图上用不同颜色的点标记每个样本位置
3. **颜色自定义**：
   - 支持使用RColorBrewer调色板（如Set1, Set2, Set3, Pastel1, Pastel2, Dark2等）
   - 支持自定义RGB颜色列表
   - 每个种群使用不同颜色
4. **可调参数**：
   - 点的大小
   - 点的透明度
   - 地图填充颜色
   - 省界边框颜色
   - 背景颜色
   - 地图显示范围（经度和纬度范围）
5. **输出格式**：同时输出PDF（矢量图）和PNG（位图，300 DPI）

## 技术要求
- 使用ggplot2和sf包进行地图绘制
- 使用rnaturalearth包获取四川省地图数据（或支持从本地shapefile读取）
- 代码结构清晰，参数集中在顶部便于修改
- 包含详细的注释说明

## 输出要求
- 生成一个完整的R脚本文件
- 脚本可以直接运行（假设数据文件路径正确）
- 包含错误处理和提示信息
- 支持中文标题和标签显示

## 参考信息
- 四川省大致经度范围：97°-110°
- 四川省大致纬度范围：26°-34°
- 建议使用coord_sf()来设置地图投影和范围
- 建议使用geom_sf()绘制省界，geom_point()绘制样本点

请生成完整的R脚本代码。
