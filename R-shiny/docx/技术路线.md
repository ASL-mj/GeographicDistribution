# 样本地理分布图可视化应用 - 技术路线

## 1. 项目概述

本项目是一个基于R语言和Shiny框架开发的交互式地理分布可视化应用，旨在帮助用户快速创建高质量的样本地理分布图，并支持导出为矢量图(PDF)和位图(PNG)格式。应用具有友好的用户界面，支持中英文双语切换，并提供丰富的地图和样式自定义选项。

## 2. 技术栈选择

### 2.1 核心技术

- **R语言**: 作为主要开发语言，R在统计分析和数据可视化方面具有强大的生态系统
- **Shiny框架**: 用于构建交互式Web应用的R包，无需前端开发知识
- **ggplot2**: 强大的绘图系统，用于生成高质量地图可视化
- **sf/maps/rnaturalearth**: 地理空间数据处理和地图绘制相关包

### 2.2 技术选择理由

| 技术选择 | 优势 | 替代方案 | 为何不选择替代方案 |
|---------|------|---------|-----------------|
| R + Shiny | 开发效率高，专为数据可视化设计，部署简单 | Python + Dash/Streamlit | 在地理空间可视化方面，R生态系统更成熟 |
| ggplot2 | 声明式语法，高度可定制，矢量输出质量高 | matplotlib/plotly | ggplot2与R集成更好，输出PDF质量更高 |
| sf包 | 现代地理空间数据处理标准，性能好 | sp包 | sf是更新的标准，性能和易用性更好 |
| rnaturalearth | 提供高质量全球地图数据，包含中国省级数据 | 自定义地图数据 | 减少数据准备工作，标准化地图边界 |

currentLang <- reactiveVal("en")
  
# 初始化时检查URL参数
observeEvent(session$clientData$url_search, {
  query <- parseQueryString(session$clientData$url_search)
  if (!is.null(query$lang)) {
    if (query$lang %in% c("en", "zh")) {
      currentLang(query$lang)
    }
  }

# 语言切换处理
observeEvent(input$switchLang, {
  newLang <- ifelse(currentLang() == "en", "zh", "en")
  currentLang(newLang)
  updateQueryString(paste0("?lang=", newLang), mode = "replace")
  session$reload()
})

# 获取当前语言的翻译文本

### 4.2 数据处理模块

应用支持两种数据来源：预设示例数据和用户上传数据，通过reactive表达式实现数据读取和实时更新：

```r
# 数据处理模块核心代码
sampleData <- reactive({
  if (input$dataSource == "sample") {
    # 使用示例数据
    read_tsv("input/经纬度信息.txt")
  } else {
    # 使用上传数据
    req(input$dataFile)
    read_tsv(input$dataFile$datapath)
  }
})

# 数据验证
validData <- reactive({
  data <- sampleData()
  # 检查必要的列是否存在
  required_cols <- c("Species", "latitude", "longitude")
  missing_cols <- required_cols[!required_cols %in% names(data)]
  
  if (length(missing_cols) > 0) {
    # 显示错误信息
    showNotification(paste("缺少必要的列:", paste(missing_cols, collapse=", ")), type="error")
    return(NULL)
  }
  
  # 检查数据类型
  if (!is.numeric(data$latitude) || !is.numeric(data$longitude)) {
    showNotification("经纬度必须是数值类型", type="error")
    return(NULL)
  }
  
  return(data)
})
```

### 4.3 地图生成

地图生成是应用的核心功能，主要通过以下步骤实现：

1. 加载世界地图数据和中国省级行政区数据
2. 特殊处理中国大陆和台湾地区数据，确保完整显示
3. 根据用户设置的地图范围、颜色方案等参数生成基础地图
4. 在地图上添加样本点，并应用用户选择的颜色方案
5. 应用主题设置，包括标题、图例、字体等

```r
# 地图生成核心代码示例
createMap <- reactive({
  # 获取有效数据
  req(validData())
  
  # 获取用户设置的参数
  Long_limit <- c(input$longRange[1], input$longRange[2])
  Lati_limit <- c(input$latiRange[1], input$latiRange[2])
  map_fill <- input$landColor
  ocean_fill <- input$oceanColor
  world_map_color <- input$worldBorderColor
  china_map_color <- input$chinaBorderColor
  
  # 设置颜色方案
  if(input$colorPalette == "custom_rgb") {
    # 自定义RGB颜色实现
    # ...
  } else if(input$colorPalette != "default") {
    color_scale <- scale_color_brewer(palette = input$colorPalette)
  } else {
    color_scale <- scale_color_discrete()
  }
  
  # 构建地图
  p <- ggplot() +
    # 绘制世界地图底纹
    geom_polygon(data = world_map %>% filter(!region==c('China','Taiwan')), 
                 aes(x = long, y = lat, group = group),
                 fill = map_fill, color = world_map_color, size=0.1) +
    # 绘制中国省界
    geom_sf(data = china_full, fill = map_fill, color = china_map_color, size=0.1) +
    # 添加样本点
    geom_point(data = validData(), 
               aes(x = longitude, y = latitude, color = Species), 
               size = input$pointSize,
               shape = as.numeric(input$pointShape)) +
    # 应用颜色方案和坐标范围
    color_scale +
    coord_sf(xlim = Long_limit, ylim = Lati_limit) +
    # 设置标签和主题
    labs(x=t$longitude_label, y=t$latitude_label, title=input$plotTitle) +
    theme_minimal() +
    theme(
      plot.title = element_text(hjust = input$titlePosition, size = input$titleSize),
      legend.position = input$legendPosition,
      panel.background = element_rect(fill = ocean_fill),
      panel.grid = element_blank()
    )
  
  return(p)
})
```

### 4.3 矢量图导出

应用支持导出高质量PDF矢量图和PNG位图，实现方式如下：

- 使用ggsave函数保存ggplot2对象
- 为PDF导出特别处理字体设置，确保跨平台兼容性
- 允许用户自定义输出尺寸和DPI

```r
# PDF导出核心代码
output$downloadPDF <- downloadHandler(
  filename = function() {
    paste0("sample_geographic_distribution_", format(Sys.time(), "%Y%m%d_%H%M%S"), ".pdf")
  },
  content = function(file) {
    # 临时修改地图的字体设置，使用系统支持的字体
    p <- createMap() + theme(
      text = element_text(family = "sans"),
      plot.title = element_text(family = "sans"),
      axis.text = element_text(family = "sans"),
      axis.title = element_text(family = "sans"),
      legend.text = element_text(family = "sans")
    )
    
    # 使用标准pdf设备
    ggsave(file, p, width = input$outWidth, height = input$outHeight, 
           dpi = input$dpi, device = "pdf")
  },
  contentType = "application/pdf"
)

# PNG导出核心代码
output$downloadPNG <- downloadHandler(
  filename = function() {
    paste0("sample_geographic_distribution_", format(Sys.time(), "%Y%m%d_%H%M%S"), ".png")
  },
  content = function(file) {
    # PNG导出不需要特殊的字体处理
    ggsave(file, createMap(), width = input$outWidth, height = input$outHeight,
           dpi = input$dpi, device = "png")
  },
  contentType = "image/png"
)
```

## 6. 技术挑战与解决方案

### 6.1 中国地图完整性问题

**挑战**：在R中绘制中国地图时，通常台湾地区会作为单独的国家级实体处理。

**解决方案**：
- 分别获取中国大陆省级数据和台湾数据
- 将台湾数据修改为省级实体
- 合并数据集后统一绘制

```r
# 中国大陆各省
china_mainland <- ne_states(country = "China", returnclass = "sf")
# 台湾单独获取
taiwan <- ne_countries(scale = "large", country = "Taiwan", returnclass = "sf")
# 将台湾修改为省级实体
taiwan$region <- "Taiwan"
taiwan$name <- "Taiwan"
# 合并数据
china_full <- rbind(
  china_mainland %>% select(name, geometry),
  taiwan %>% select(name, geometry)
)
```

### 6.2 PDF导出字体兼容性

**挑战**：在不同操作系统上，PDF导出时字体渲染可能出现问题，特别是中文字体。

**解决方案**：
- 在导出PDF时临时修改字体设置为系统通用字体
- 提供字体选择选项，但在导出时统一处理
- 使用sans字体族确保跨平台兼容性

### 6.3 自定义颜色方案实现

**挑战**：允许用户为不同种类的样本点自定义RGB颜色。

**解决方案**：
- 使用条件面板动态显示RGB输入控件
- 限制自定义颜色数量（前5种）以简化界面
- 使用scale_color_manual实现自定义颜色映射

```r
# 自定义RGB颜色实现
if(input$colorPalette == "custom_rgb") {
  # 获取唯一种类列表
  species_list <- unique(sampleData()$Species)
  n_species <- min(length(species_list), 5)
  
  # 创建RGB颜色
  custom_colors <- c(
    rgb(input$rgb1R, input$rgb1G, input$rgb1B, maxColorValue = 255),
    rgb(input$rgb2R, input$rgb2G, input$rgb2B, maxColorValue = 255),
    # ... 更多颜色
  )[1:n_species]
  
  # 创建命名向量
  names(custom_colors) <- species_list[1:n_species]
  
  color_scale <- scale_color_manual(values = custom_colors)
}
```

### 6.4 大数据集处理

**挑战**：当用户上传包含大量样本点的数据集时，可能导致渲染性能下降。

**解决方案**：
- 实现数据采样机制，当数据点超过阈值时自动采样
- 优化绘图函数，减少不必要的计算
- 提供数据过滤选项，允许用户选择性显示部分数据

```r
# 大数据集处理示例
sampleDataProcessed <- reactive({
  data <- sampleData()
  # 如果数据点过多，进行采样
  if(nrow(data) > 5000) {
    # 随机采样5000个点
    set.seed(123) # 确保结果可重复
    data <- data[sample(nrow(data), 5000), ]
    # 显示采样提示
    showNotification("数据点过多，已自动采样5000个点进行显示", type = "warning")
  }
  return(data)
})
```
