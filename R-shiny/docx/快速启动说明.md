# 样本地理分布图可视化应用 - 快速启动说明

## 环境要求

1. 安装 R 软件环境 (版本 >= 4.0)

   - Windows 用户：从 [CRAN 官网](https://cran.r-project.org/bin/windows/base/) 下载安装包
   - Mac 用户：从 [CRAN 官网](https://cran.r-project.org/bin/macosx/) 下载安装包
   - Linux 用户：根据不同发行版使用包管理器安装

2. 推荐安装 RStudio (可选)
   - 从 [RStudio 官网](https://www.rstudio.com/products/rstudio/download/) 下载安装

## 启动方法

### 方法一：直接运行启动脚本（最简单）

1. 打开终端/命令提示符
2. 进入应用程序目录：
   ```
   cd 应用程序所在路径/back
   ```
3. 执行启动脚本：
   ```
   Rscript run.R
   ```
4. 系统将自动安装必要的包并启动应用程序
5. 应用程序将在默认浏览器中打开

### 方法二：在 RStudio 中运行

1. 打开 RStudio
2. 打开 app.R 文件（文件 > 打开文件）
3. 点击右上角的"Run App"按钮
4. 应用程序将在 RStudio 内置浏览器或默认浏览器中启动

## 常见问题

1. **包安装失败**

   - 确保网络连接正常
   - 尝试手动安装包：
     ```R
     install.packages(c("shiny", "tidyverse", "ggplot2", "maps", "sf", "RColorBrewer", "rnaturalearth", "rnaturalearthdata", "rnaturalearthhires"))
     ```

2. **找不到示例数据**

   - 确保"input"文件夹中有"经纬度信息.txt"文件
   - 或者使用应用程序中的"上传自己的数据"选项

3. **应用程序运行很慢**

   - 地图库首次加载可能需要一些时间
   - 后续启动将更快

4. **地图不显示**
   - 检查 R 包是否正确安装
   - 检查数据文件格式是否正确（应包含 Species、latitude、longitude 三列）
