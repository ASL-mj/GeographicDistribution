# 样本地理分布可视化应用上线步骤

## 使用 shinyapps.io 部署应用

### 1. 注册 shinyapps.io 账号

- 访问[shinyapps.io](https://www.shinyapps.io/)官网
- 点击"Sign Up"按钮注册新账号
- 选择适合的套餐（有免费选项可用于测试）
- 完成注册并验证邮箱

### 2. 安装并配置 rsconnect 包

- 在 R 环境中安装 rsconnect 包

  ```r
  install.packages("rsconnect")
  ```

- 获取账号令牌和密钥

  - 登录 shinyapps.io
  - 在右上角点击账号名称，选择"Tokens"
  - 点击"Show"或"Add Token"生成新的令牌和密钥
  - 点击"Show Secret"查看密钥

- 在 R 中配置账号信息
  ```r
  library(rsconnect)
  rsconnect::setAccountInfo(
    name='你的账户名',  # shinyapps.io用户名
    token='你的令牌',   # 从网站获取的token
    secret='你的密钥'   # 从网站获取的secret
  )
  ```

### 3. 准备应用文件

- 确保所有文件路径使用相对路径，不要使用绝对路径
- 检查必要的数据文件（经纬度信息.txt）是否放在正确位置
- 确保所有依赖包都已在 app.R 开头通过 library()函数声明

### 4. 部署应用

- 使用 deployApp()函数部署

  ```r
  rsconnect::deployApp(
    appDir = "R-shiny/app",           # 应用目录路径
    appName = "sample-geographic",     # 应用在shinyapps.io上的名称
    appTitle = "样本地理分布可视化"    # 应用显示标题
  )
  ```

- 等待上传和部署完成，系统会自动打开浏览器显示部署的应用
- 部署成功后，就可以访问应用了

### 5. 应用维护

- 每次更新应用后，重复第 4 步重新部署
- 可以查看应用访问日志和错误报告
- 如果发现问题，可以在本地修复后重新部署
