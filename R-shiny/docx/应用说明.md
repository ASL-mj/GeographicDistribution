# 样本地理分布可视化应用技术说明文档

## 应用概述

样本地理分布可视化应用是一个基于 R Shiny 框架开发的交互式地理信息可视化工具，专为科研人员和数据分析师设计。该应用能够在地图上展示不同种类样本的空间分布，支持用户上传自定义数据，并提供丰富的可视化参数调整功能，最终可以导出高质量的矢量图（PDF）和光栅图（PNG）用于学术出版或报告。

## 技术架构

### 开发语言与环境

- **主要编程语言**：R 语言（版本 4.0.0 或更高）
- **开发环境**：RStudio IDE
- **应用框架**：Shiny（交互式 Web 应用框架）

### 核心依赖包

1. **shiny**：构建交互式 Web 应用程序的核心框架
2. **tidyverse**：数据处理和分析的集合包，包括：
   - dplyr：数据操作和转换
   - tidyr：数据整理和重构
   - readr：数据读取与解析
3. **ggplot2**：基于图形语法的数据可视化系统，用于生成高质量地图和图表
4. **maps**：提供基础地图数据
5. **sf**：简单要素（Simple Features）空间数据处理
6. **RColorBrewer**：提供优化的配色方案
7. **rnaturalearth**：提供高质量自然地球数据
8. **rnaturalearthdata**：自然地球数据的扩展包
9. **rnaturalearthhires**：高分辨率自然地球数据（用于详细的地理边界）

### 文件结构

- **app.R**：应用的主程序文件，包含 UI 和服务器逻辑
- **input/经纬度信息.txt**：示例数据文件（TSV 格式）

## 核心功能实现

### 多语言支持

应用实现了中英文双语界面支持，通过以下机制实现：

1. 使用翻译字典（translations 列表）存储不同语言的界面文本
2. 通过 URL 参数（?lang=en 或?lang=zh）控制当前显示语言
3. 提供语言切换按钮，实现无刷新语言切换

```r
# 定义翻译字典
translations <- list(

    "app_title" = "样本地理分布图可视化",
    # 更多中文翻译...
  )

# 获取当前语言
currentLang <- reactiveVal("en")
```

### 数据处理模块

应用支持两种数据来源：预设示例数据和用户上传数据，通过 reactive 表达式实现数据读取和实时更新：

```r
sampleData <- reactive({
  if (input$dataSource == "sample") {
    # 使用示例数据
    read_tsv("input/经纬度信息.txt")
  } else {
    # 使用上传数据
    req(input$dataFile)
    read_tsv(input$dataFile$datapath)
  }
})
```

### 地图渲染

地图渲染部分是应用的核心，综合利用多个地理信息包实现：

1. 使用`map_data("world")`获取世界地图基础数据
2. 使用`ne_states`和`ne_countries`获取中国大陆和台湾地区的高精度地理数据
3. 通过 ggplot2 的绘图系统构建地图图层：
   - 世界地图底图
   - 中国省级行政区边界
   - 样本点数据可视化

```r
createMap <- reactive({
  # 获取世界地图数据
  world_map <- map_data("world")

  # 获取中国地图数据
  china_mainland <- ne_states(country = "China", returnclass = "sf")
  taiwan <- ne_countries(scale = "large", country = "Taiwan", returnclass = "sf")

  # 构建地图
  p <- ggplot() +
    # 绘制世界地图底图
    geom_polygon(data = world_map %>% filter(!region==c('China','Taiwan')),
                 aes(x = long, y = lat, group = group),
                 fill = map_fill, color = world_map_color, size=0.1) +
    # 绘制中国省级边界
    geom_sf(data = china_full, fill = map_fill, color = china_map_color, size=0.1) +
    # 添加样本点
    geom_point(data = sampleData(),
               aes(x = longitude, y = latitude, color = Species),
               size = input$pointSize,
               shape = as.numeric(input$pointShape)) +
    # 应用颜色方案
    color_scale +
    coord_sf(xlim = Long_limit, ylim = Lati_limit) +
    # 设置标签和主题
    labs(x=t$longitude_label, y=t$latitude_label, title=input$plotTitle) +
    theme_minimal() +
    theme(...)
})
```

### 颜色方案实现

应用提供多种颜色方案选择：

1. 使用 RColorBrewer 预设配色方案
2. 支持自定义 RGB 颜色设置（最多 5 个种类）
3. 可自定义地图底图的海洋和陆地颜色

```r
# 设置颜色方案
if(input$colorPalette == "custom_rgb") {
  # 创建自定义RGB颜色
  species_list <- unique(sampleData()$Species)
  n_species <- min(length(species_list), 5)

  custom_colors <- c(
    rgb(input$rgb1R, input$rgb1G, input$rgb1B, maxColorValue = 255),
    # 更多自定义颜色...
  )[1:n_species]

  color_scale <- scale_color_manual(values = custom_colors)
} else if(input$colorPalette != "default") {
  color_scale <- scale_color_brewer(palette = input$colorPalette)
} else {
  color_scale <- scale_color_discrete()
}
```

### 导出功能

应用支持将可视化结果导出为 PDF 和 PNG 格式，通过`downloadHandler`实现：

```r
# 下载PDF
output$downloadPDF <- downloadHandler(
  filename = function() {
    paste0("sample_geographic_distribution_", format(Sys.time(), "%Y%m%d_%H%M%S"), ".pdf")
  },
  content = function(file) {
    # 处理字体设置
    p <- createMap()
    p <- p + theme(text = element_text(family = "sans"), ...)

    # 保存PDF
    ggsave(file, p, width = input$outWidth, height = input$outHeight,
           dpi = input$dpi, device = "pdf")
  },
  contentType = "application/pdf"
)

# 下载PNG
output$downloadPNG <- downloadHandler(
  filename = function() {
    paste0("sample_geographic_distribution_", format(Sys.time(), "%Y%m%d_%H%M%S"), ".png")
  },
  content = function(file) {
    ggsave(file, createMap(), width = input$outWidth, height = input$outHeight,
           dpi = input$dpi, device = "png")
  },
  contentType = "image/png"
)
```

## 技术实现亮点

1. **响应式设计**：所有参数调整实时反映在地图上，无需刷新页面
2. **多语言支持**：完整的中英文界面切换功能
3. **高度定制化**：用户可调整超过 20 项可视化参数
4. **专业地图渲染**：结合多个专业地理信息包，提供精确的地理边界
5. **高质量输出**：支持科研出版级别的矢量图和光栅图导出

## 技术局限和解决方案

1. **中文字体支持**：

   - **问题**：R 的 PDF 设备对中文字体支持有限
   - **解决方案**：在 PDF 导出时使用系统支持的通用字体

2. **大数据集处理**：

   - **问题**：大量样本点可能导致性能下降
   - **解决方案**：数据预处理和分组显示

3. **浏览器兼容性**：
   - **问题**：不同浏览器可能显示不一致
   - **解决方案**：使用 Shiny 的内置响应式设计和浏览器适配
